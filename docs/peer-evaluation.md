# Peer evaluation (optional)

Each member fills one copy about every *other* member. Score 1 (poor) to 5 (excellent).

| Evaluator | Teammate | Contribution | Reliability | Communication | One concrete thing they did well |
|---|---|---|---|---|---|
| | | | | | |
| | | | | | |
| | | | | | |

**Contribution:** did they deliver real work that others used? **Reliability:** did they meet agreed deadlines and
review others' pull requests on time? **Communication:** did they say early when they were stuck or when a plan
changed?

Evidence to attach: `git shortlog -sn --no-merges`, and links to the pull requests you reviewed.
